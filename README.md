# The Love Chronicles

Romance à choix dans le Londres de la Régence (1813) — chapitres 1 à 7.

**Jouer :** https://juliencvt.github.io/the-love-chronicles/ (installable sur Android depuis Chrome : menu ⋮ → « Installer l'application »).

- `index.html`, `assets/`, `icons/`, `manifest.webmanifest`, `sw.js` : le jeu publié (application web installable, fonctionne hors connexion).
- `source/` : les fichiers de travail (moteur, histoire FR/EN, décors) et le script qui assemble `index.html`.
